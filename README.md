# Sistem Manajemen Kategori Buku Perpustakaan
Nama : Muhammad Humam Sukma (60324087)
## Deskripsi Aplikasi
Aplikasi ini merupakan sistem manajemen kategori buku perpustakaan yang digunakan untuk mengelola data kategori buku secara efisien.
Fitur utama dalam aplikasi ini meliputi:
### Fitur
- **READ** : Menambahkan kategori buku
- **UPDATE** : Mengedit kategori
- **DELETE** : Menghapus kategori
- **READ** : Menampilkan daftar kategori
  
Aplikasi ini dibuat untuk mempermudah pengelolaan kategori buku dalam sistem perpustakaan agar lebih terstruktur dan mudah diakses.
