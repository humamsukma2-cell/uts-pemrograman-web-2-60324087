# Sistem Manajemen Kategori Buku Perpustakaan
Nama : Muhammad Humam Sukma (60324087)
## Deskripsi Aplikasi
Aplikasi ini merupakan sistem manajemen kategori buku perpustakaan yang digunakan untuk mengelola data kategori buku secara efisien.
Fitur utama dalam aplikasi ini meliputi:
### Fitur
- **READ** : Menambahkan kategori buku
- **UPDATE** : Mengedit kategori
- **DELETE** : Menghapus kategori
- **READ** : Menampilkan daftar kategori
  
Aplikasi ini dibuat untuk mempermudah pengelolaan kategori buku dalam sistem perpustakaan agar lebih terstruktur dan mudah diakses.
## Cara Menjalankan Aplikasi
### Langkah Instalasi
1. Clone Repository ini : https://github.com/humamsukma2-cell/uts-pemrograman-web-2-60324087.git
2. Pastikan sudah instal XAMPP (Apache + Mysql)
3. Copy Folder ke htdocs XAMPP : C:\xampp\htdocs\uts_perpustakaan_60324061
4. Import Database
   - Buka phpMyAdmin `localhost/phpmyadmin`
   - Buat Database Baru `uts_perpustakaan_60324087`
   - Klik tab "**Import**"
   - pilih file `uts_perpustakaan_60324087.sql`
   - klik "**GO**"
5. Jalankan Apache dan Mysql di XAMPP
   - Klik **Start**
6. Jalankan Aplikasi di Browser `localhost/uts_60324087`
